# Developer Portfolio

A clean, responsive personal portfolio website built with React and JavaScript to showcase projects, technical skills, and software engineering experience.

**Live Demo:** [portfolio-murex-xi-92.vercel.app](https://portfolio-murex-xi-92.vercel.app)

## Features
- Responsive design optimized for mobile and desktop devices
- Project showcase with live links and source code details
- Clean, modular component structure with ESLint configured

## Run Locally
1. Clone the repository:
   `git clone https://github.com/GOu7tha3/PORTFOLIO.git`
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm run dev`
